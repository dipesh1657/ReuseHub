# ReuseHub
#ReuseHub

ReuseHub is a full-stack web application where users can buy, sell, and exchange items sustainably. Built with React and Express.js.


##Features

1. User Authentication (Signup / Login)
2. Buy Items – View items listed for sale
3. Sell Items – List your own items
4. Exchange Items – Exchange items with others
5. My Profile – View your profile information
6. My Items – Manage your listed items
7. Responsive Design – Works on all devices


##Tech Stack

#Frontend
1. React.js
2. React Router DOM
3. CSS
4. Vite

#Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
